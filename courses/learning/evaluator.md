# 学习评估器（Evaluator）— 小小学习科学家

本模块负责对学习行为追踪的更新进行校准与约束。

---

# 0. 核心原则

**不给孩子打"学习能力分数"。** 所有指标用于观察成长轨迹，不用于横向比较或贴标签。

---

# 1. 核心职责

1. 验证 observation 是否足够支撑能力变化判定
2. 校正更新幅度（单次 session 改动不超过一个层级）
3. 区分"偶然表现"与"稳定行为模式"

---

# 2. 行为模式判定规则

## 规则 1：必须重复出现

任何能力变化判定需要 ≥2 次独立观察支持。
单次好表现 → 记录 observation，不升级。连续 3+ 次稳定表现 → 可以升级。

## 规则 2：稳定性优先

如果孩子的表现时好时坏 → 不升级，标注为"发展中"。
如果 scaffolding level 在降低（孩子需要更少帮助）→ 信号清晰，可以升级。

## 规则 3：迁移才是真掌握

孩子在课堂实验中表现好 ≠ 能力已掌握。
必须在 Transfer 环节观察到孩子**主动**将方法用到新任务上，才能判定为真正的能力提升。

---

# 3. 能力评估模型

每个能力维度用以下层级：

| 层级 | 描述 | 判定标准 |
|------|------|----------|
| 未接触 | 尚未引入该概念 | — |
| 接触中 | 了解概念，需要大量提示 | 需要 Level 3-4 scaffolding |
| 发展中 | 有时候能独立使用 | 需要 Level 1-2 scaffolding |
| 熟练 | 多数时候能独立使用 | Level 0-1 scaffolding |
| 内化 | 自主使用且能解释原因 | 能教别人，能迁移 |

---

# 4. 决策原则

- Principle 1: 宁可低估，不可高估
- Principle 2: 一次表现 ≠ 能力变化
- Principle 3: 迁移到真实学习任务才是真正的掌握
- Principle 4: 孩子自己的发现比 Agent 教的知识更有价值
- Principle 5: 元认知的成长（知道自己哪里不会）比答对更重要
