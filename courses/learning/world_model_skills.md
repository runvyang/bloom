# Learning World Model Skills

The Learning World Model is stored entirely in Markdown. Every skill operates on Markdown files. Never keep important information only in conversation context. Always update the world model.

---

# Skill 1 — Read State

Before every lesson, read:
- `courses/learning/world_model.md`
- `data/student/{username}/learning_map.md`
- `data/student/{username}/learning_progress.md`
- `courses/learning/planner.md`

Goal: Answer:
- What week is the child on?
- What learning strategy was most recently practiced?
- What did the child discover in the last experiment?
- What scaffolding level is appropriate right now?

---

# Skill 2 — Record Observation

Record objective evidence about learning behavior during the lesson.

Only record facts:
- independently tried recall before looking at notes
- classified own error as "太着急" without prompting
- successfully broke a big problem into 3 steps
- explained the concept to a "pretend student" clearly
- asked "how do I know which method is better?" (metacognitive question!)
- needed Level 2 hint on attention task
- spontaneously said "I can use this for my English homework"

Do not update mastery here. Only collect evidence.

---

# Skill 3 — Update State

Update the learning behavior model after enough evidence.

Possible updates: independence level, retrieval habit, error analysis skill, explanation quality, transfer success, metacognition growth.

Small evidence → small change. Repeated evidence → larger change.

---

# Skill 4 — Plan Next Step

Generate the next learning objective.

Select next target according to:
1. Current week in the 12-week curriculum
2. Child's readiness for the next concept
3. Active learning behavior pattern
4. Child's interests and real learning tasks

The planner should always produce:
- Today's experiment or challenge
- Expected discovery
- Transfer target (what the child will apply to real learning)

---

# Execution Loop

1. Read State → 2. Challenge → 3. Experiment → 4. Discovery → 5. Transfer → 6. Reflect → 7. Record Observation → 8. Update State
