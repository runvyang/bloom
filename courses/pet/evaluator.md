# 学习评估器（Evaluator）— PET 冲刺

本模块负责对 pet_progress.md 的更新进行校准与约束。

---

# 1. 核心职责

1. 验证 evidence 是否足够支撑 mastery 更新
2. 校正更新幅度（单次最多一个层级）
3. 区分"识别"与"运用"两个维度
4. 跟踪拼写和语法错误模式

---

# 2. Mastery 更新规则

## 规则 1：evidence driven
- 词汇 recognition：学生能正确理解 ≥3 次 → 可升级
- 词汇 application：学生能正确拼写并运用 ≥2 次 → 可升级
- 语法：学生能在 3 个不同句子中正确运用 → 可升级
- 阅读：单次做对不足以升级，需要连续 2 篇同类文章表现稳定
- 写作：单篇好作文不足以升级，需要多次一致表现

## 规则 2：更新幅度限制
单次 session 每个技能最多 +1 级 / -1 级。

## 规则 3：螺旋复习优先
已学内容连续 3 天未复习 → 置信度下调。
遗忘不记录 delta，而是安排复习任务。

---

# 3. 词汇双维度评估

```
vocabulary_mastery = (recognition_level + application_level) / 2
```

- 识别（recognition）：看词知义、听词知义
- 运用（application）：正确拼写、正确造句、正确搭配

两个维度差距过大（识别≫运用）→ 需要刻意练习转化。

---

# 4. 错误模式分类

| 类型 | 示例 | 处理 |
|------|------|------|
| 拼写错误 | "breakfest" | 记入拼写错误清单，安排听写 |
| 语法错误 | 漏三单 s | 专项语法练习 |
| 词汇误用 | much/many 混淆 | 对比教学 |
| 搭配错误 | "make homework" | 短语专项练习 |
| 阅读偏差 | 主旨理解错误 | 降低文章难度 |

错误模式连续出现 2 次才记录为 delta。

---

# 5. 决策原则

- Principle 1: 宁可低估，不可高估
- Principle 2: 识别不等于运用
- Principle 3: 拼写和语法错误是独立维度
- Principle 4: 8 周冲刺期，优先查漏补缺而非完美主义
- Principle 5: 考试能力 > 系统知识
