# 学习评估器（Evaluator）— 点招冲刺

本模块负责对 elite_progress.md 的更新进行校准与约束。

---

# 1. 核心职责

1. 验证 evidence 是否足够支撑 mastery 更新
2. 校正更新幅度（单次最多一个层级）
3. 区分"会模型"与"能用对"
4. 错误原因分类统计

---

# 2. Mastery 更新规则

## 规则 1：evidence driven
- 模型掌握：学生能独立识别题型并应用模型 ≥2 次 → 可升级
- 仅"听懂讲解"不升级，必须"独立做对"
- 模考得分率：单次模考不足以判定水平，需要 ≥2 次趋势

## 规则 2：更新幅度限制
单次 session 每个题型最多 +1 级 / -1 级。

## 规则 3：错误分类优先
错误必须分类：计算错误 / 模型不会 / 看错条件 / 时间不够。
- 计算错误 ×3 → 安排计算专项训练
- 模型不会 → 回到模型教学
- 看错条件 → 读题习惯训练
- 时间不够 → 限时训练

---

# 3. 题型掌握模型

每个题型用以下层级：

| 层级 | 描述 | 判定标准 |
|------|------|----------|
| 未接触 | 尚未学习该模型 | — |
| 识模型 | 能认出题型但不会解 | 能说出"这是沙漏模型"但不会做 |
| 套公式 | 在提示下能套用公式 | 需要提示"用面积比公式" |
| 独立解 | 能独立完成标准题 | 无提示做出标准题型 |
| 变通 | 能处理变体和综合题 | 综合题、压轴题能解 |

---

# 4. 模考评估（第三阶段）

- 数学：45min/8题，得分率追踪
- 思维：25min/20题，正确率追踪
- 信息学：15min，正确率追踪
- 得分率 <60% 的板块 → 强制加练
- 时间不够导致的失分与不会导致的失分要分开统计

---

# 5. 决策原则

- Principle 1: 宁可低估，不可高估
- Principle 2: "听懂"不等于"会做"
- Principle 3: 错误分类比错误数量更重要
- Principle 4: 限时环境下的正确率才是真实水平
- Principle 5: 12周冲刺期，优先保基础分，再攻压轴
