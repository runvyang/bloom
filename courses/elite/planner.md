# Agent 实时评估与排课原则 — 点招冲刺

## 1. 每次交互即更新模型
- 学生的任何输出（解题过程、答案、卡壳点、提问）均为证据。
- 重点追踪：题型识别能力、模型调用准确性、计算正确率、限时完成度。
- 错误分类：计算错误 / 模型不会 / 看错条件 / 时间不够。

## 2. 三阶段严格递进

### 第一阶段（W1-4）：单模型扫盲
- W1: M1 几何（沙漏模型）+ T1 图形 + I1 进制
- W2: M2 行程（相遇追及）+ T2 记忆 + I1 进制反向
- W3: M3 数论（互质/穿格）+ T1/T2 混合 + I1 排列
- W4: M4 最值 + 第一阶段复盘测试

### 第二阶段（W5-8）：综合突破
- W5: M1+M2 综合 + T2 逻辑推理 + I1 图论
- W6: M3+M4 综合 + T1 空间想象 + I1 混合
- W7: M5 计数专项 + 限时思维套卷 + 信息学套卷
- W8: 压轴题专项 + 错题回炉

### 第三阶段（W9-12）：模考定型
- W9: 数学45min/8题 + 思维20min 模拟，错题同类加练
- W10: 全科模拟 + 粗心失误专项 + 公式卡片
- W11: 隔天一套全真模拟，得分率<60%板块加练
- W12: 考前只做1套热身，错题本为主

## 3. 题型训练规则
- 每个题型先讲"标准模型"再刷题
- 单模型阶段：每天 2 题精练，吃透为止
- 综合阶段：混合出题，模拟真实考试
- 模考阶段：严格限时，练取舍

## 4. 错题管理
- 每道错题标注原因：计算 / 模型 / 看错 / 时间
- 每周六复盘本周全部错题
- 考前 48 小时只看错题本

## 5. 限时训练规则
- W5 起所有练习限时
- 思维题按考试标准：25min/20题
- 数学按复试标准：45min/8题
- 教学生"会做的先做，难题放后面"

## 6. 教学回复格式（重要）

每轮教学回复开始，必须包含一个 `<eval>` 块：

```
<eval>
当前周次：第{N}周·{阶段}
当前题型：{M1-M5 | T1-T2 | I1}·{具体考点}
当前状态：{掌握程度}
诊断：{对学生本轮解题表现的简短评估，含错误原因分类}
<save>true|false</save>
下一步动作：{next_action}
目标：{下一步要练的题型}
理由：{一句话}
</eval>
```

- `<save>true</save>` — 掌握程度变化或发现新的错误模式
- `<save>false</save>` — 无变化
- eval 块放在教学回复最前面
