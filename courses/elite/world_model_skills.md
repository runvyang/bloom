# Elite World Model Skills

The Learning World Model is stored entirely in Markdown. Every skill operates on Markdown files. Never keep important information only in conversation context. Always update the world model.

---

# Skill 1 — Read State

Before every lesson, read:
- `courses/elite/world_model.md`
- `data/student/{username}/elite_map.md`
- `data/student/{username}/elite_progress.md`
- `courses/elite/planner.md`

Goal: Answer:
- What week/phase is the student in?
- Which problem type (M1-M5/T1-T2/I1) is this week's focus?
- What standard model should the student be using?
- What error categories are most frequent?

---

# Skill 2 — Record Observation

Record objective evidence during the lesson.

Only record facts:
- identified sandglass model within 30 seconds
- applied area ratio formula correctly but arithmetic error in step 3
- couldn't start problem — asked "what model is this?"
- misread condition (confused 相遇 with 追及)
- completed 8 problems in 45min with 75% accuracy
- stuck 5 minutes on butterfly model, needed hint

Do not update mastery here. Only collect evidence.

---

# Skill 3 — Update State

Update the student model after enough evidence.

Possible updates: model mastery, error patterns (计算/模型/看错/时间), speed, mock exam scores.

Every update supported by recorded observations. Small evidence → small change. Repeated evidence → larger change.

Special rules:
- 2 consecutive correct uses of a model → upgrade
- Same error category appearing 3+ times → record as error pattern
- Mock exam results tracked separately (score rate per section)

---

# Skill 4 — Plan Next Step

Generate the next learning objective.

Select next target according to:
1. Current week in the 12-week plan
2. The week's focus problem type
3. Active error patterns needing repair
4. Mock exam score rates (phase 3)

The planner should always produce:
- Today's problem type and model
- Number of practice problems (with time limits if phase ≥2)
- Expected mastery improvement
- Exit criteria

---

# Execution Loop

1. Read State → 2. Teach/Practice → 3. Record Observation → 4. Update State

The Markdown files are the single source of truth. Conversation history is temporary. The world model is permanent.
